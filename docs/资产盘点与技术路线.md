### 1.2 PPSD 是什么（技术背景）

- **全称**：Plant Phased siRNA Database（植物相位小干扰 RNA 数据库）
- **归属**：南京农业大学 农学院 作物生物信息学组（CBI），导师 **黄骥 教授**
- **网址**：<http://cbi.njau.edu.cn/PPSD>（v1.0 于 2024/1/2 上线）
- **生物学含义**：phasiRNA 是植物特有的一类非编码小 RNA，由 miRNA 剪切 PHAS locus 后
  以 21 nt 为周期依次切割产生，再去调控下游靶基因。整条链路叫 **phasiRNA 调控通路**：

  ```
  miRNA（phase initiator） → 剪切 → PHAS locus → 相位切割 → phasiRNA → 靶基因
  ```

- **收录规模**（论文数字）：8 个物种、219 个降解组验证的 phase initiator、
  7765 个 PHAS loci、104204 条 phasiRNA、61131 个降解组验证的靶基因
- **8 个物种**：水稻、大豆、玉米、拟南芥、葡萄、油菜、柑橘、棉花

## 三、技术路线

### 3.1 目标形态

复刻「数据库访问网页」这条完整链路，**每个环节都用真实数据跑通**：

```
浏览器（Vue 3 + vue-router + Bootstrap + ECharts）   :5173
      │   axios → HTTP GET /api/...
      ▼
后端（Node.js + Express + pg 驱动）                  :3000
      │   SQL 查询
      ▼
数据库（PostgreSQL 16.9）                            :5432
```

三个程序各跑各的、通过网络通信 —— 这就是「全栈」的物理形态，也是最容易讲清楚的架构。

### 3.2 技术选型（及理由）

| 层 | 选型 | 为什么 |
|---|---|---|
| 前端框架 | Vue 3 + Vite | 你已有的基础，不用重学 |
| 路由 | vue-router 4 | Browse → 详情 → 返回，需要真实 URL |
| UI | Bootstrap 5 | **学长发的参考链接之一**，且原站就是 Bootstrap |
| 图表 | ECharts 5 | **学长发的参考链接之一**，原站也用 |
| 后端 | Node.js + Express | 与前端同语言，不用学第二种语言 |
| 数据库 | PostgreSQL | **原站就是 PostgreSQL 13.3**，与服务器一致 |
| 部署（将来） | 学校 Linux + PM2 | 数据必须留在校内服务器 |

Bootstrap 和 ECharts 是**学长明确发过的链接**，用它们等于部分对齐了课题组的预期。
唯一没对齐的是后端语言（PHP vs Node），这件事必须问。

### 3.3 数据模型

依据原站导出数据的**真实字段**设计，共 6 张表（对应论文里 9 张表中的 4 张业务表）：

| 表 | 说明 | 行数 |
|---|---|---|
| `species` | 物种维表 | 8 |
| `clusters` | PHAS loci（原库 clusters 表），19 字段 | 7760 |
| `phas_seq` | PHAS locus 核酸序列（原库 PHAS 表） | 7760 |
| `phasi_rna` | phasiRNA 主表 | 104166 |
| `phasi_rna_target` | phasiRNA 的降解组验证靶基因（原库 PTI 表拆出来的一半） | 465863 |
| `initiator` | phase initiator（触发 miRNA） | 11786 |

> **设计取舍**：原站的导出是「一条 phasiRNA × 一条靶基因」拉平成的**宽表**
> （水稻 50508 条 phasiRNA 摊成 41 万行）。这里拆成 `phasi_rna` + `phasi_rna_target`
> 两张表，既避免了大量重复，也让「一条 phasiRNA 有多个靶基因」这层关系显式化 ——
> 这正是关系型数据库该做的事，讲的时候也是加分项。

   并在轴标题上标出**相邻间距中位数** —— 直接就能看出 21 nt 的周期性。可交互、可缩放。
2. **表格全列可排序**：原站只有部分列可排序，我们 19 列全部可排序，且支持关键词过滤。
3. **架构清晰**：前后端完全分离，数据库访问做成可切换驱动，本地开发和服务器部署零改动。

### 6.2 技术风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| npm 默认镜像证书过期 | 装不了新包 | 加 `--registry=https://registry.npmjs.org/` |
| 本地 PostgreSQL 是 `trust` 认证 | 任何本地程序都能连 | 仅限 demo；上服务器必须改 `scram-sha-256` |
