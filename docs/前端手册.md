# PPSD 前端手册

给「在这个前端上加新功能」的人看的。看完这一份，你应该能在不破坏现有设计一致性
的前提下，加一个新页面、新接口、新图表。

配套阅读：[`资产盘点与技术路线.md`](资产盘点与技术路线.md)（项目背景与规划）、
[`../README.md`](../README.md)（怎么把项目跑起来）。

---

## 一、五条规矩（先看这个）

违反这五条，代码会跑，但会慢慢毁掉整个界面的一致性。

1. **不写死颜色、字体、圆角、间距。** 全部走 `var(--c-*)` / `var(--font-*)` / `var(--r-*)` / `var(--sp-*)`。
   想换配色就改 `src/styles/tokens.css` 一个文件，不该动任何组件。
2. **不写行内样式。** 用 `src/styles/base.css` 里的类；确实只属于某个页面的样式，
   写进该组件的 `<style scoped>`。行内样式只允许用于纯布局尺寸（比如给图表容器一个高度）。
3. **所有面向用户的文字都走 `t()`。** 英文是默认语言，中文是切换项，两边都要有。
   任何直接写死在模板里的字符串，切到另一种语言时就会露馅。
4. **不引新的 CSS 框架。** Bootstrap 只引了 `reboot` / `grid` / `utilities` 三个文件当布局工具，
   刻意没引它的组件样式 —— 页面长得"像个模板"就是那么来的。
5. **加新图表前先读第六节。** ECharts 有两个已经踩过的坑，写错了图就是白的。

## 二、设计系统

### 2.1 视觉方向

**v2「Botanical Ink」：暖纸白 + 墨绿正文 + 深植物绿强调色 + 物种专属色板。**
（v1 是纯灰阶单色；v2 恢复了克制的色彩，但规则不变 —— 一切颜色仍出自 tokens.css）

- **基底**：`--c-bg` 是带绿意的暖纸白，正文 `--c-text` 是墨绿黑而不是纯黑，
  数据密集界面长时间阅读更稳，也和"植物"主题呼应。
- **强调色**：深植物绿（四个色阶：主色 / hover / 极浅底 / 描边），
  出现在按钮、链接、选中态、图表主系列上。
- **物种色板 `--c-sp-osa` … `--c-sp-ghi`**：8 个物种各占一个色相
  （绿/叶绿/金/蓝/紫/青/橙/玫红）。物种圆点、Browse 左栏、图表系列共用 ——
  用户在任何一个页面学会的颜色，到另一个页面仍然成立。
  `utils/echarts.js` 的 `speciesColor(abbr)` 是唯一的取色入口。
- **版面**：玻璃拟态吸顶导航（`backdrop-filter`）+ bento 卡片网格 +
  左栏导航 + 右栏信息卡。首页 hero 是深绿渐变压植物摄影图
  （Unsplash 免费授权图，已本地打包进 `src/assets/img/`），
  右侧放缓慢旋转的**相位环**（`components/PhaseRing.vue`）——
  三圈圆环按等相位分布圆点，呼应"以 21 nt 为周期依次切割"。
- **状态徽章**：`.badge--yes/-no/-warn` 恢复了低饱和的绿/灰/琥珀，
  仍然不用大红大绿。

### 2.2 改配色 / 改字体（最常见的需求）

只改 `src/styles/tokens.css`：

```css
:root {
  --c-accent: #7a2e1d;   /* 换成别的颜色，全站按钮/链接/图表跟着变 */
  --c-accent-hover: #5c2013;
  --c-accent-tint: #faf3f0;
  --c-accent-border: #e6d2ca;
}
```

**注意**：

1. 强调色有四个色阶（主色 / hover / 极浅底 / 描边），换色时四个都要给，
   否则选中行、提示块、徽章会露出旧颜色。`--c-accent-tint` 必须是非常浅的同色相，
   不能直接填主色。
2. **图表的两档灰是独立变量** `--c-chart-1` / `--c-chart-2`，不和强调色共用 ——
   图表经常需要两个同色系的深浅档，而强调色只有一个值。
3. **深色区块里的主按钮要手动反色**。`.on-dark` 内部 `--c-accent` 被重定义成白色，
   而 `.btn--primary` 是 `background: var(--c-accent); color: #fff`，
   不处理会变成白底白字整个消失。`base.css` 里已经加了 `.on-dark .btn--primary` 的覆盖，
   新增深色区块时注意别绕过它。
4. 想恢复成有色方案，只改 `tokens.css` 里那几个值即可 —— 组件代码一行都不用动。

深色首屏另有一组反色令牌，通过 `.on-dark` 类生效：

```html
<section class="hero on-dark"> ... </section>
```

这个类会把 `--c-text` / `--c-border` / `--c-accent` 等变量在**该容器内部**重定义，
所以子元素不需要写任何"深色模式"的条件判断。要新做一个深色区块，加 `.on-dark` 就行。

### 2.3 字体与字号规范

**四个家族，各司其职，不混用：**

| 变量 | 字体 | 用在哪 |
|---|---|---|
| `--font-display` | Space Grotesk | 站点名、`h1`–`h4`、`page-title`、`card__title`（只有拉丁字形，中文自动回退到黑体系，不会出现宋体） |
| `--font-sans` | Inter Variable | 正文、按钮、表单、界面文字 |
| `--font-mono` | IBM Plex Mono | 基因号、转录本号、序列、坐标、统计数字 |

**字号是严格枚举的七档**（参照 GitHub Primer / IBM Carbon 的做法），
全站不允许出现第七档以外的字号，也不允许裸写 px/rem：

| 档 | 变量 | 值 | 用途 |
|---|---|---|---|
| 微字 | `--fs-xs` | 12px | 徽章、表头、字段标签、辅助标注 |
| 中字 | `--fs-sm` | 14px | 表格数据、按钮、导航、次级正文 |
| 正文 | `--fs-base` | 15px | 正文默认（body） |
| 大字 | `--fs-md` | 16px | 导语、卡片标题、强调正文 |
| 标题3 | `--fs-lg` | 20px | 三级标题 |
| 标题2 | `--fs-xl` | 24px | 二级标题 |
| 标题1 | `--fs-2xl` | 30px | 一级标题 |
| 展示 | `--fs-3xl` | 40px | 页面展示标题 |

**等宽字体的使用规则**（这条最容易做错）：

- 序列、坐标、ID、统计数字 → 必须等宽（`.mono` / `.cell-seq` / `.num`），与同档文字同字号（最多 0.92em 微缩）
- 普通正文、按钮文字、表格注释 → 禁止等宽
- 代码/序列展示块（`.seq-block`）用等宽 + 正常字号（14px），因为序列要逐碱基扫读

字体文件用 `@fontsource` **打包进本地**（见 `src/main.js` 的 import），不走 Google Fonts CDN，
所以断网演示不会掉字体。要加字重就去 `main.js` 里 import 对应的 CSS 文件。

**等宽字体的使用规则**（这条最容易做错）：

- 序列、坐标、ID → 必须等宽，加 `.mono` 或 `.cell-seq`
- 统计数字 → 必须等宽（等宽数字不会跳动，读起来稳）
- 普通正文、按钮文字、表格里的注释 → **不要**用等宽，会很吵

### 2.4 间距与圆角

间距是 4px 基准的阶梯：`--sp-1`(4px) 到 `--sp-8`(64px)。别自己算新数字。

圆角只有三档：`--r-sm`(3px) / `--r-md`(5px) / `--r-lg`(8px) / `--r-pill`。
**刻意不用 Bootstrap 那种大圆角** —— 数据界面里圆角越大越显廉价。

## 三、组件库速查（`src/styles/base.css`）

加新页面时从这里挑类，不要另造一套。

### 布局

| 类 | 用途 |
|---|---|
| `.page` | 页面容器，居中 + 左右留白 |
| `.page-body` | 内容区上下留白（每个视图根节点都要有 `.page.page-body`） |
| `.section` / `.section__head` / `.section__title` | 页面内的分区标题（带下划线） |
| `.row` / `.row--wrap` / `.stack` / `.spacer` | 横排 / 可换行横排 / 竖排 / 占位撑开 |

> ⚠️ 首页的深色首屏是**通栏**的，所以它不受 `.page-body` 约束 ——
> `App.vue` 的 `<main>` 刻意没有内边距，内边距由每个视图自己加。新页面记得根节点写
> `<div class="page page-body">`，否则内容会贴到顶栏上。

### 容器

| 类 | 用途 |
|---|---|
| `.card` / `.card__head` / `.card__title` / `.card__hint` / `.card__body` | 卡片面板 |
| `.card__body--flush` | 内容要贴边的卡片（配 `.kv` 或 `.table-wrap` 用） |
| `.stats` / `.stat` / `.stat__n` / `.stat__l` | 一排统计数字（用 1px 分隔线，不是阴影） |

### 数据展示

| 类 | 用途 |
|---|---|
| `.table-wrap` | 表格滚动容器（宽表格必须套，否则撑破页面） |
| `table.data` | 数据表。表头自动大写小字号，行 hover 变强调色浅底 |
| `th.is-sortable` + `.sort-ind` | 可排序表头与排序箭头 |
| `.cell-seq` | 序列单元格（更小、更紧的字距） |
| `.mono` | 等宽单元格 |
| `.kv` / `.kv__k` / `.kv__v` | 详情页的键值表（标签左、值右） |
| `.seq-block` | 长序列显示块（可滚动、自动断行） |
| `.badge` + `--yes` / `--no` / `--soft` / `--accent` / `--warn` | 状态徽章 |
| `.pager` / `.pager__ctl` | 分页条 |

### 表单与导航

| 类 | 用途 |
|---|---|
| `.field` / `.field__label` | 表单字段与标签（标签是大写小字号） |
| `.input` / `.select` / `.textarea` | 输入控件（focus 时是强调色描边 + 浅底光圈） |
| `.searchbar` | 输入框 + 按钮的组合 |
| `.tabs` / `.tabs__item` + `.is-active` | 选项卡 |
| `.seg` / `.seg__btn` + `.is-active` | 分段控件（语言切换用的就是这个） |
| `.crumbs` | 面包屑 |
| `.note` + `--warn` | 提示条（左侧 3px 强调色竖线） |

### 状态

| 类 | 用途 |
|---|---|
| `.state` | 加载中 / 空结果 |
| `.state--error` + `.state__hint` | 错误状态 |
| `.state__spinner` | 细线转圈（比默认转圈安静） |

### 按钮

`.btn` 是基类，必须配一个变体：

- `.btn--primary` — 强调色实底，一屏最多一个
- `.btn--secondary` — 白底描边，次要操作
- `.btn--ghost` — 无底无边，第三级（如"重置""清空"）
- 尺寸：`.btn--sm` / 默认 / `.btn--lg`；宽度：`.btn--block`

## 四、加一个新页面

以"加一个统计页 `/stats`"为例，四步：

**① 写视图** `src/views/StatsView.vue`

```vue
<script setup>
import { ref, onMounted } from 'vue'
import api from '../api/ppsd.js'
import { t } from '../i18n/index.js'

const data = ref(null)
const loading = ref(true)
const error = ref('')

onMounted(async () => {
  try {
    data.value = await api.stats()
  } catch (e) {
    error.value = e.message
  } finally {
    loading.value = false
  }
})
</script>

<template>
  <div class="page page-body">
    <h1 class="page-title">{{ t('stats.title') }}</h1>
    <p class="page-sub">{{ t('stats.sub') }}</p>

    <div v-if="loading" class="state">
      <div class="state__spinner"></div>
      {{ t('state.loading') }}
    </div>
    <div v-else-if="error" class="state state--error">{{ error }}</div>
    <div v-else class="card">
      <!-- ... -->
    </div>
  </div>
</template>
```

**② 注册路由** `src/main.js`

```js
import StatsView from './views/StatsView.vue'
// routes 数组里加：
{ path: '/stats', name: 'stats', component: StatsView },
```

**③ 加导航**（如果要出现在顶栏）`src/App.vue` 的 `navItems`

```js
{ name: 'stats', key: 'nav.stats', to: '/stats' },
```

**④ 加文案** `src/i18n/index.js` 的 `messages.en` 和 `messages.zh` **两边都要加**

```js
en: { 'nav.stats': 'Stats', 'stats.title': 'Statistics', ... }
zh: { 'nav.stats': '统计',  'stats.title': '数据统计', ... }
```

> 只加一边是这里最常见的错误。漏了的 key 不会报错，界面上会直接显示 key 本身
> （比如 `stats.title`）—— 这是故意的，比显示空白好排查。

## 五、加一个新接口

**① 后端**：在 `backend/src/routes/` 下新建或用现有的路由文件，照现有风格写。

```js
import { Router } from 'express';
import { query } from '../db/index.js';   // ⚠️ 一定用这个，别自己建连接池

export const statsRouter = Router();

statsRouter.get('/stats/detail', async (req, res, next) => {
  try {
    const { rows } = await query(
      'SELECT species, count(*)::int AS n FROM clusters GROUP BY species',
      [],                                  // ⚠️ 参数一律用 $1 $2 占位，永远不要拼字符串
    );
    res.json({ rows });
  } catch (e) {
    next(e);                               // ⚠️ 交给统一错误处理
  }
});
```

然后在 `backend/src/server.js` 里挂载：

```js
import { statsRouter } from './routes/stats.js';
app.use('/api', statsRouter);
```

**② 前端**：在 `src/api/ppsd.js` 的 `api` 对象里加一个方法。

```js
statsDetail: () => http.get('/stats/detail'),
```

页面里 `import api from '../api/ppsd.js'` 然后 `await api.statsDetail()`。

> `ppsd.js` 里的 axios 拦截器已经把后端的 `{ error, message }` 转成了可读异常，
> 所以页面里只需要 `try/catch` 然后显示 `e.message`，不用自己判断状态码。

**③ 数据库**：如果新接口要查不存在的列，改
`backend/src/db/schema.sql`（建表）和 `src/db/load.js`（灌数据），
然后 `npm run db:load`（约 35 秒）。**两个文件都要改** —— 只改一个的话，
下次重新灌库时改动就丢了。

## 六、图表规范（ECharts）

全站图表统一走 **`src/utils/echarts.js` 的 `useChart()` composable** ——
不要再手写 `echarts.init`。它一次性解决了下面所有坑：

```js
import { useChart, darkTooltip, cssVar, speciesColor } from '../utils/echarts.js'

const { el: chartEl, setOption, getChart } = useChart((data) => ({
    tooltip: darkTooltip({ trigger: 'item' }),   // 深色 tooltip，全站一套
    series: [{ type: 'pie', data: data.map(s => ({
        value: s.phasi_rna, itemStyle: { color: speciesColor(s.abbr) } }) }],
}))
// 模板里：<div ref="chartEl" class="chart"></div>
// 数据到位后：setOption(data)   （内部自动 nextTick，避开"坑一"）
```

composable 内置：`notMerge=true`、ResizeObserver 自动 resize、
卸载时 `dispose()`、实例挂到已销毁 DOM 时自动重建（"坑二"）、
语言切换自动重画（图例/轴标签跟着换）。
需要绑定点击事件（如环图扇区跳转）用 `getChart().on('click', ...)`，
在 `setOption` 之后的 `nextTick` 里绑。

颜色一律 `cssVar('--c-accent')` / `speciesColor(abbr)` 从 CSS 变量读，
换 tokens.css 时图表自动跟随。

### 前人踩过的两个坑（composable 已堵上，但要知道原理）

**坑一：图是白的 —— 容器还没渲染就 init 了。**
数据加载完就画图，但如果页面用 `v-if="loading"` 包着内容，画图时容器根本不存在，
`echarts.init(null)` 静默失败。正确顺序是先关 loading、`await nextTick()` 再画。
用 `useChart` 时顺序由 composable 保证。

**坑二：图表实例挂在已经被销毁的 DOM 上。**
容器外面有 `v-if` 时，切换数据会销毁重建容器而实例还指着旧 DOM。
`useChart` 每次画之前检查 `chart.getDom() !== el.value`，不一致就 dispose 重建。

### 其他的账

- 纵轴量级差得多的时候用**对数轴**（各物种数据量差了 160 倍，线性轴会把小的压成 0）
- X 轴数据范围很窄的时候加 `scale: true`，否则 21 nt 的间距会被压成一条线
- 19 列宽表格里长文本列（annotation）必须单行省略（`.cell-clip` + `title`），
  否则它会被挤压换行，把整行撑到 100px 高

## 七、i18n 规范

`src/i18n/index.js` 是一个 ref + 一张字典表，没有用 vue-i18n（两种语言、一套文案，
用不上那个库的复数/插值/懒加载）。用法：

```js
import { t, locale, setLocale } from '../i18n/index.js'

t('nav.home')            // 取文案；t 内部读的是响应式 ref，切语言会自动重渲染
locale.value             // 'en' | 'zh'
setLocale('zh')          // 切换，会写 localStorage 并同步 <html lang>
```

### key 命名约定

用 `模块.用途`，小驼峰：

| 前缀 | 用途 | 例 |
|---|---|---|
| `nav.` | 导航 | `nav.browse` |
| `hero.` | 首屏 | `hero.title` |
| `home.` | 首页内容 | `home.chart.title` |
| `browse.` / `search.` / `blast.` / `download.` / `help.` | 各页面自己的文案 | `blast.btn` |
| `col.` | 表格列头（跨页面复用） | `col.phaseScore` |
| `f.` | 详情页字段名 | `f.annotation` |
| `pager.` / `state.` / `common.` | 通用 | `pager.prev` |

### 三条硬规矩

1. **两边都加。** 加 key 时 `messages.en` 和 `messages.zh` 一起加。
2. **不要在模板里写死文字。** 包括标点符号之外的任何内容。
3. **不要把后端的文案直接显示。** 后端一次只能返回一种语言。下载页原来显示的是
   后端 `note` 字段（英文），切到中文时就露馅了 —— 后来改成前端自己的 `t('download.hint')`。
   后端返回的说明性文字只能当 fallback，或者干脆不用。

### 长文案怎么办

像"帮助"页那种整段的说明，放在组件的 `<script setup>` 里，用 `{ en, zh }` 对象 + 一个 `pick()`：

```js
const pick = (o) => (o ? o[locale.value] || o.en : '')
const glossary = [{ k: 'P-value', v: { en: '...', zh: '...' } }]
```

```html
<div v-for="g in glossary" :key="g.k">{{ pick(g.v) }}</div>
```

好处是文案和它对应的字段名挨在一起，改的时候不用在 i18n 文件和组件之间来回跳。

## 八、踩过的坑（都是真事）

写代码时如果觉得"这里怪怪的"，先看看是不是这几个：

| 坑 | 现象 | 原因与解法 |
|---|---|---|
| **自定义类撞 Bootstrap 的 `.row`** | 一行的按钮变成全宽堆叠；统计数字竖着排 | `bootstrap-grid.css` 的 `.row` 会给**所有直接子元素**加 `width:100%`。我们的 `.row` 撞名后就被它接管了。自定义工具类不要叫 `.row`（已改名 `.rowline`） |
| **间距工具类被 `!important` 压死** | 改 `base.css` 里的 `.mt-4` 没反应 | `bootstrap-utilities.css` 用 `!important` 定义了一套同名类，优先级更高。所以间距直接用 Bootstrap 那套，不要在 base.css 里重复定义 |
| **表头可点但数据没排序** | 箭头移到了被点的列，顺序却没变 | 前端把**所有**列都做成了可排序，而后端只认白名单里的字段（`routes/loci.js` 的 `SORTABLE`），不在白名单的会静默回退。前端要维护一份一致的集合（`BrowseView.vue` 的 `SORTABLE`） |
| **区间检索每行链接到 `/locus/undefined`** | ID 列空白，点进去 404 | 区间接口返回的字段是 `phas_loci`，而结果表格统一读 `id`。跨接口复用表格时要把字段名对齐 |
| **基因号/转录本结果点进去 404** | 检索结果里的 `LOC4346635` 链接报"找不到位点" | 基因号和转录本号**不是**位点 ID。只有 `kind === 'locus'` 之类的结果才能连到 `/locus/:id`，其他类型只显示文本 |
| **Strand 列的 `-`** | 负链 phasiRNA 的链显示成空 | 源数据里 `-` 表示**负链**，是真实取值，不是缺失占位符。通用空值清洗函数会把它清成 NULL（影响 22.6 万行）。见 `backend/src/db/load.js` 的 `strandOf()` |
| **坐标 `start > end`** | 区间检索漏掉部分位点 | 负链位点在源数据里 `genome_start > genome_end`。查询要用 `LEAST()` / `GREATEST()` 归一化 |
| **图表空白** | 图表区域全白 | 见第六节"坑一" |
| **首屏有白缝** | 深色首屏上面多一条白边 | `main` 和视图都套了带内边距的 `page-body`，重复了。现在 `main` 不带内边距，由视图自己控制 |
| **FASTA 记录数翻倍** | 3366 条序列显示成 6731 条 | FASTA 每条序列占两行（`>` 行 + 序列行），不能按"行数-1"数，要数 `>` 的个数 |
| **序列比对慢到 17 秒** | 长序列比对要等十几秒 | 在 JS 里对每条候选扫全序列找种子，而有的位点长达 6 万碱基。改成先在 SQL 里用 `strpos` 预筛，降到 0.7 秒。见 `backend/src/routes/blast.js` 文件头 |
| **`npm install` 报证书错误** | `CERT_HAS_EXPIRED` | 默认镜像 `r.cnpmjs.org` 证书过期，加 `--registry=https://registry.npmjs.org/` |
| **切了语言但某段文案不变** | 首页"调控通路"卡切中文后仍是英文 | 文案在 `<script setup>` 里用普通 `const` 存了一次 `t()` 的结果 —— 不是响应式。放 `computed` 里即可（`t()` 内部读响应式 `locale`，computed 会自动重算） |
| **表格行高突然 100px** | Browse 表格某行特别高 | 19 列挤压下无 `min-width` 的 annotation 列被压成四五行换行，行高被最高的那格撑起来。用 `.cell-clip` 单行省略 + `title` 悬停看全文 |
| **换了颜色但徽章还是旧色** | 部分元素颜色没跟着变 | 强调色有四个色阶，见 2.2 |
| **中文界面里混着英文** | 个别文字不跟着切 | 要么少了 `t()`，要么文案来自后端。见第七节 |
